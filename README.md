# Ruang Baca

Sistem Manajemen Perpustakaan berbasis Laravel untuk UTS Pemrograman Web III.

## Fitur
- Login dan Register
- Dashboard
- Daftar Buku
- Tambah Buku
- Detail Buku
- Edit Buku
- Hapus Buku
- Pencarian Buku
- Filter Kategori

## Teknologi
- Laravel
- PHP
- MySQL
- Blade
- Tailwind CSS
